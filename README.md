# خبرنامه و فید زنده سروستان (Sarvestan Feed)

این مخزن منبع انتشار زنده خبرنامه، اطلاعیه‌ها، مجله آزاد سرونامه و شعرنامه برای برنامه سروستان (نسخه‌های وب و اندروید) است.

آدرس توزیع بدون محدودیت (CDN):
`https://cdn.jsdelivr.net/gh/mjb4khshi/Sarvestan_feed@main/feed.json`

---

## کانال‌های فعال

1. **اطلاعیه‌ها (`announcements`)**: اطلاعیه‌های رسمی، تقویم آموزشی، امور دانشجویی، هشدارهای حذف و اضافه و سیستم.
2. **سرونامه (`sarvnameh`)**: گاهنامه آزاد دانشجویی، تجربیات زیسته، مقالات، یادداشت‌های آزاد، ستون دانشجویان و تحلیل‌ها.
3. **شعرنامه (`shernameh`)**: گزیده اشعار کهن و معاصر، ابیات ناب، دلنوشته‌های شبانه و آرامش ادبی در روزهای شلوغ دانشگاه.

---

## نحوه انتشار پست جدید با فایل مارک‌داون

کافی است یک فایل با پسوند `.md` داخل پوشه `posts/` ایجاد کنید (مثلاً `posts/my-story.md`):

```markdown
---
title: تیتر نوشته شما
channelId: sarvnameh
date: ۲۴ مهر ۱۴۰۵
badge: ستون آزاد
color: primary
summary: چکیده کوتاه یک یا دو خطی...
actionText: مشاهده منبع
actionUrl: https://t.me/s4rvest4n
---

# سرفصل اول
متن کامل نوشته با فرمت مارک‌داون.

> بیتی از شعر یا نقل قول

- مورد اول
- مورد دوم

**متن پررنگ** و `کد درون‌خطی`
```

### ساخت خودکار `feed.json`:
- **روی گیت‌هاب**: به محض ذخیره یا کامیت فایل در گیت‌هاب، اکشن گیت‌هاب خودکار فایل `feed.json` را بازتولید و ثبت می‌کند.
- **به صورت دستی**: می‌توانید با دستور `node build.cjs` یا `npm run build` فایل `feed.json` را تولید کنید.
